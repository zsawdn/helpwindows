    Windows快捷键

    Win10/11可用

    2026年8月21日 · Windows

    Windows键：

    Windows=调出 开始菜单（Start）

    Windows+E=调出 文件资源管理器(explorer.exe)

    Windows+R=调出 运行(Run.exe)

    Windows+U=调出 设置-辅助功能

    Windows+|=调出 设置(SystemSettings.exe)

    Windows+P=调出 投影

    Windows+A=调出 网络连接设置

    Windows+S=调出 搜索框(Search)

    Windows+D/M=回到桌面(Desktop)

    Windows+F=调出 反馈中心(PilotshubApp.exe)

    Windows+G=调出 游戏中心(XBOX Game Bear)

    Windows+H=调出 语音服务

    Windows+K=调出 投放

    Windows+L=锁屏

    Windows+Z=调出 系统程序布局_(仅Windows11可用)

    Windows+X=开始菜单右键

    Windows+V=调出Windows官方表情库

    Windows+B=调出 隐藏的程序图标

    Windows+N=调出 通知

    Windows+, <= 预览桌面(不是返回桌面)

    Windows+F1=调出网络链接“在Windows中如何获取帮助”

    Windows+ + =调出 放大镜

    Windows+Ctrl+D=新建虚拟桌面

    Windows+ Ctrl + 左/右方向键=在多个虚拟桌面中切换（新建了1个或以上虚拟桌面有效）

    Win + Ctrl + F4=关闭当前的虚拟桌面（新建了1个或以上虚拟桌面有效）

    Win + Ctrl + 数字(1-9)=切换到任务栏上对应位置图标的应用（未运行应用不生效）

    Ctrl键

    Ctrl+C=复制（选中文件时）

    Ctrl+V=粘贴（选中文件时）

    Ctrl+X=剪切（选中文件时）

    Ctrl+Z=撤销

    Ctrl+Y=恢复/重做被撤销的操作

    Ctrl+A=选中全部内容

    Ctrl+S=保存

    Ctrl+N=新建文件资源管理器新建窗口

    Ctrl+P=打开“打印”对话框

    Ctrl+O=打开“打开文件”窗口

    Ctrl+F=查找内容

    Ctrl+D=删除文件到回收站（与Delete键作用相同）

    Ctrl+H=“查找历史”功能（仅限浏览器）

    Ctrl+鼠标滚轮=调整文件的图标/浏览器内容大小

    Ctrl+Shift+ESC=打开任务管理器

    Ctrl+ESC=打开开始菜单（与Win键作用相同）

    Ctrl+Alt+Delete=打开安全选项界面

    Ctrl+F4=关闭当前活动文档

    Ctrl+W=关闭当前标签/窗口

    Ctrl+Shift=切换出入法（安装了多个输入法时有效）

    Ctrl+Alt+Tab=使用方向键在打开的应用之间进行切换

    Ctrl+Space=打开或关闭中文输入法编辑器 (IME)

    Ctrl + Shift + N=新建文件夹（文件资源管理器）

    Alt键

    Alt+Tab=在打开的应用之间切换

    Alt+F4=强制关闭当前应用（若桌面无窗口，则弹出关机对话框）

    Alt+Space=打开当前窗口的系统菜单

    Alt+Esc=按窗口打开的先后顺序循环切换（不弹出预览界面，直接切换）

    Alt+Enter/双击=查看文件或文件夹的属性（选中文件/文件夹时有效）

    文件资源管理中有效：

    Alt=激活菜单（出现快捷键）

    Alt+F=打开 文件 (File) 菜单

    Alt+D=选中地址栏（方便输入路径）

    Alt+V=打开 查看（View）菜单

    Alt+左方向键=在文件资源管理器或浏览器中 返回 上一页

    Alt+右方向键=在文件资源管理器或浏览器中 前进 到下一页

    Shift键

    Shift=切换输入法输入模式（中文/英文）

    Shift+Delete=永久删除文件（不会移动至回收站，直接删除，选中文件时有效）

    Shift+方向键=

    在文本或文件中连续选中内容（从光标处向箭头方向扩展选择）

    Shift+单击=在文件列表中，连续选中两个点击位置之间的所有文件（配合 Ctrl 可精细选择）

    Shift+Home=选中从光标位置到行首的所有文本

    Shift+End=选中从光标位置到行尾的所有文本

    Shift+重启=进入Windows高级选项（WinRE）

    Shift+关机=下一次开机进入Windows高级选项（WinRE）
